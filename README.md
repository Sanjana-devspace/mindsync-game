# 🎮 Simon Says: mindsync Game

A classic memory game where the computer flashes a growing sequence of colors and you have to repeat it perfectly. Every level adds one more step. One wrong click and it's game over!

🔗 **Live Demo:** https://Sanjana-devspace.github.io/mindsync-game/

## 🕹️ How to Play
1. Press **any key** on your keyboard to start.
2. Watch the game flash a color.
3. Click the colored buttons in the same order.
4. Each level adds one more color to the sequence.
5. A wrong click turns the screen red and shows your score.
6. Press any key to play again and beat your high score!

## ✨ Features
- Random color sequence generated every game
- Flash animation when the game shows a color
- Separate click animation so you see your own input
- Live level counter
- Game over screen with a red screen flash
- Your score and **highest score** shown after every game
- Instant restart with any key press

## 🛠️ Built With
- **HTML5**: game layout with four numbered color buttons
- **CSS3**: Flexbox layout, rounded buttons and flash effects
- **JavaScript**: game logic, arrays, event listeners and `setTimeout`
